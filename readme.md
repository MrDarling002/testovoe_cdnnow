# Calculator

HTTP-калькулятор с нативными библиотеками C и Rust, атомарным обновлением
состояния, метриками с ограниченной памятью и генератором нагрузки.

## Требования

| Инструмент | Версия | Назначение |
|------------|--------|------------|
| Go | 1.22+ | сборка, тесты |
| GCC | любая | компиляция C через cgo |
| Rust | stable | сборка нативной библиотеки |
| ОС | Linux x86-64 / arm64 | cgo + линковщик |

## Сборка

```bash
make build
